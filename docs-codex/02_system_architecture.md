# Upgrade-analyzer Codex CLI版 システムアーキテクチャ

## 1. システム概要

### 1.1 アーキテクチャの特徴
- **プロンプトファイルベース**: プロンプトファイル（`prompts/<name>.md`）でAIに分析を実行
- **Codex CLI依存**: Codex CLIのスラッシュコマンド機能とWeb検索機能を活用
- **ファイルベース**: データベースを使用せず、ファイルシステムでデータを管理
- **メタ情報駆動**: JSON メタ情報でコマンドの定義と引数ヒントを提供

## 2. システム構成

### 2.1 主要コンポーネント

#### 2.1.1 Codex CLI
- **役割**: ユーザーインターフェース、スラッシュコマンド実行環境
- **機能**: 
  - スラッシュコマンド `/prompts:upgrade-analyzer` の認識
  - Web検索機能によるWeb検索
  - AIとの対話

#### 2.1.2 プロンプトファイル
- **ファイル**: `prompts/upgrade-analyzer.md`
- **役割**: AIに実行させる分析指示を定義
- **機能**:
  - JSON メタ情報（name, description, argument_hint）
  - プロンプト本文（Markdown形式）
  - 変数置換（引数の受け取り）

#### 2.1.3 AI分析エンジン
- **実装**: Codex CLI内蔵のAI機能
- **役割**: プロンプトに基づいて分析を実行
- **機能**:
  - Web検索による情報収集
  - 情報の分析・分類
  - レポートの生成

#### 2.1.4 ファイル管理システム
- **実装**: ファイルシステム
- **役割**: レポートの保存と管理
- **機能**:
  - レポートファイルの保存
  - タイムスタンプ付きファイル名生成
  - ディレクトリ管理

### 2.2 データフロー

```
1. ユーザー入力
   ↓
2. スラッシュコマンド実行 (/prompts:upgrade-analyzer)
   ↓
3. プロンプトファイル読み込み (prompts/upgrade-analyzer.md)
   ↓
4. JSON メタ情報解析
   ↓
5. 引数解析とプロンプト本文の準備
   ↓
6. AI分析実行
   ↓
7. Codex Web検索機能でWeb検索
   ↓
8. 情報収集・分析
   ↓
9. レポート生成
   ↓
10. ファイル保存
    ↓
11. 結果表示
```

## 3. 技術スタック

### 3.1 必須技術
- **Codex CLI**: 最新版（スラッシュコマンド、Web検索機能）
- **Markdown**: プロンプトファイルとレポート形式
- **JSON**: メタ情報形式
- **ファイルシステム**: データ保存

### 3.2 使用しない技術
- **プログラミング言語**: 使用しない（プロンプトのみ）
- **データベース**: 使用しない（ファイルベース）
- **外部API**: 使用しない（Codex Web検索機能のみ）
- **Webサーバー**: 使用しない（ローカル実行）

## 5. 処理フロー

### 5.1 メイン処理フロー

#### 5.1.1 初期化
1. スラッシュコマンド `/prompts:upgrade-analyzer` の認識
2. 引数の解析（製品名、バージョン、プロジェクト情報）
3. プロンプトファイルの読み込み

#### 5.1.2 プロンプト処理
1. JSON メタ情報の解析
2. 引数ヒントの表示
3. プロンプト本文の準備
4. 変数置換の実行

#### 5.1.3 分析実行
1. AI分析エンジンへのプロンプト送信
2. Codex Web検索機能によるWeb検索実行
3. 情報収集・分析の実行

#### 5.1.4 レポート生成
1. 分析結果の整理
2. Markdown形式でのレポート生成
3. ファイル保存の実行

#### 5.1.5 完了
1. 保存されたファイルパスの表示
2. 処理完了の確認

### 5.2 エラーハンドリング

#### 5.2.1 入力エラー
- 引数不足の場合のエラーメッセージ
- バージョン形式の不正な場合の警告

#### 5.2.2 処理エラー
- プロンプトファイルが見つからない場合のエラー
- インターネット接続エラーの処理
- ファイル保存エラーの処理

## 11. Cursor版との違い

### 11.1 実装方式
- **Cursor版**: `.cursorrules` ファイルでスラッシュコマンド定義
- **Codex版**: `prompts/<name>.md` ファイルでプロンプト定義

### 11.2 Web検索機能
- **Cursor版**: Browser機能
- **Codex版**: Codex CLI Web検索機能

### 11.3 メタ情報
- **Cursor版**: プロンプト内に埋め込み
- **Codex版**: JSON メタ情報として分離

### 11.4 引数処理
- **Cursor版**: プロンプト内で変数置換
- **Codex版**: 引数ヒントとプロンプト本文の分離
