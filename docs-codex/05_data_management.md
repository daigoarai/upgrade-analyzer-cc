# Upgrade-analyzer Codex CLI版 データ管理仕様

## 1. データ管理概要

### 1.1 データ管理方式
- **ファイルベース**: データベースを使用せず、ファイルシステムでデータを管理
- **Markdown形式**: レポートはMarkdown形式で保存
- **JSON形式**: メタ情報はJSON形式で管理
- **ローカル保存**: すべてのデータはローカルファイルシステムに保存

### 1.2 データの種類

| データ種類 | 形式 | 保存場所 | 説明 |
|------------|------|----------|------|
| プロンプトファイル | JSON + Markdown | `prompts/upgrade-analyzer.md` | スラッシュコマンドの定義とプロンプト |
| 生成レポート | Markdown | `reports/` | 生成された影響分析レポート |
| 実例レポート | Markdown | `examples/` | 参考用の実例レポート |
| 設計書 | Markdown | `docs-codex/` | Codex版設計書 |
| 設定ファイル | 各種 | プロジェクトルート | プロジェクト設定 |

### 2.2 ファイル命名規則

#### 2.2.1 レポートファイル
```
{製品名}_{バージョンFrom}_to_{バージョンTo}_{YYYYMMDD}_{HHMMSS}.md
```

**例**:
```
nextjs_15.4_to_15.5.3_20250128_143022.md
react_18.2.0_to_18.3.1_20250128_150315.md
postgresql_14.1_to_15.0_20250128_161045.md
```

#### 2.2.2 実例レポートファイル
```
{製品名}_{バージョンFrom}_to_{バージョンTo}.md
```

**例**:
```
nextjs_15_to_15.5.3.md
react_18.2_to_18.3.1.md
postgresql_14.1_to_15.0.md
```

#### 2.2.3 設計書ファイル
```
{番号}_{名前}.md
```

**例**:
```
01_requirements.md
02_system_architecture.md
03_detailed_design.md
```

### 2.3 特殊文字の処理

| 文字 | 処理方法 | 例 |
|------|----------|-----|
| スペース | `_` に置換 | `Next.js 15.4` → `Next.js_15.4` |
| 特殊文字 | `-` に置換 | `React@18.2.0` → `React-18.2.0` |
| 日本語 | そのまま使用 | `Next.js` → `Next.js` |
| パス区切り | `-` に置換 | `next/link` → `next-link` |

## 3. プロンプトファイル管理

### 3.1 プロンプトファイル構造

#### 3.1.1 ファイル形式
```markdown
{
  "name": "upgrade-analyzer",
  "description": "ソフトウェア製品のバージョンアップ影響分析レポートを生成",
  "argument_hint": "<製品名> <バージョンFrom> <バージョンTo> [プロジェクト情報]"
}
---
# プロンプト本文

## 1. 基本指示
- 調査対象の明確化
- 調査手順の詳細
- 出力形式の指定

## 2. 調査項目
- リリース状況確認
- 中間バージョン特定
- 段階的差分分析
- 依存関係分析
- クロスブラウザ互換性分析

## 3. レポート生成
- メタ情報生成
- 差分サマリ生成
- 主要変更点分類
- テスト戦略提案
- リスクアセスメント

## 4. ファイル保存
- 自動保存指示
- ファイル命名規則
- 保存場所指定
```

> メモ: スラッシュコマンドの引数は `{引数1}`（製品名）、`{引数2}`（バージョンFrom）、`{引数3}`（バージョンTo）、`{引数4}`（プロジェクト情報・任意）としてプロンプト本文に渡される。本文で使用している `{製品名}` などの表記は、これらのプレースホルダーをもとにAIが文脈に合わせて展開するためのガイドである。

#### 3.1.2 JSON メタ情報管理

| フィールド | 型 | 必須 | 説明 | 制約 |
|------------|----|----|------|------|
| name | string | 必須 | スラッシュコマンド名 | 英数字、ハイフン、アンダースコアのみ |
| description | string | 必須 | コマンドの説明 | 100文字以内 |
| argument_hint | string | 必須 | 引数のヒント | 200文字以内 |

## 12. トラブルシューティング

### 12.1 よくある問題

#### 12.1.1 ファイルアクセスエラー
- **問題**: ファイルにアクセスできない
- **原因**: 権限不足、ファイルロック
- **解決**: 権限確認、ファイルロック解除

#### 12.1.2 ディスク容量不足
- **問題**: ディスク容量が不足
- **原因**: 大量のレポートファイル
- **解決**: 古いファイルの削除、ディスク容量の拡張

#### 12.1.3 ファイル破損
- **問題**: ファイルが破損している
- **原因**: 書き込みエラー、ディスクエラー
- **解決**: バックアップからの復元、ファイル再生成
