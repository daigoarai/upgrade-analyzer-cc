# Upgrade-analyzer Codex CLI版 設計書

## 1. 概要

### 1.1 プロジェクト名
Upgrade-analyzer Codex CLI版

### 1.2 目的
ソフトウェアのバージョンアップ時の影響分析を自動化し、Codex CLI環境で開発チームが安全かつ効率的にアップグレードを実施できるよう支援するツールを提供する。

### 1.3 特徴
- **プロンプトファイルベース**: `prompts/<name>.md` 形式でプロンプトを定義
- **Codex CLI依存**: Codex CLIのスラッシュコマンド機能とWeb検索機能を活用
- **ファイルベース**: データベースを使用せず、ファイルシステムでデータを管理
- **メタ情報駆動**: JSON メタ情報でコマンドの定義と引数ヒントを提供

## 3. 主要機能

### 3.1 基本機能
- **スラッシュコマンド実行**: `/prompts:upgrade-analyzer` でバージョンアップ影響分析を実行
- **プロンプトファイルベース分析**: `prompts/upgrade-analyzer.md` を使用してAIに分析を実行
- **Codex Web検索機能活用**: Codex CLIのWeb検索機能を使用して公式情報を収集
- **レポート生成**: 収集した情報を基に包括的なMarkdownレポートを生成
- **自動ファイル保存**: 生成されたレポートを `reports/` フォルダにタイムスタンプ付きで自動保存

### 3.2 分析機能
- **リリース状況確認**: 指定されたバージョンが実際にリリースされているかを確認
- **中間バージョン特定**: FromバージョンからToバージョンまでの全中間バージョンを特定
- **段階的差分分析**: 各バージョン間の変更点を個別に調査し、累積的な影響を分析
- **依存関係分析**: 推移的依存関係（依存の依存）の既知問題を調査
- **クロスブラウザ互換性分析**: 全プラットフォーム（Windows/macOS/iOS/Android）での互換性を分析

### 3.3 レポート機能
- **メタ情報生成**: 調査日、リリース状況、中間バージョン一覧などのメタ情報を生成
- **差分サマリ生成**: 全バージョンでの累積変更数をまとめたサマリを生成
- **主要変更点分類**: Breaking Changes、セキュリティ修正、バグ修正、新機能追加を分類
- **テスト戦略提案**: 優先度別・プラットフォーム別のテスト観点を提案
- **リスクアセスメント**: リスク項目ごとに発生確率・影響度・対応策を評価

## 6. 使用方法

### 6.1 セットアップ
1. Codex CLI最新版をインストール
2. プロジェクトをクローン
3. `prompts/upgrade-analyzer.md` を配置
4. 動作確認

### 6.2 コマンド実行
```bash
/prompts:upgrade-analyzer <製品名> <バージョンFrom> <バージョンTo> [プロジェクト情報]
```

> 引数はCodex CLIによって `{引数1}`（製品名）、`{引数2}`（バージョンFrom）、`{引数3}`（バージョンTo）、`{引数4}`（プロジェクト情報・任意）としてプロンプト本文に渡される。本文内での `{製品名}` などの表記は、これらプレースホルダーに基づいてAIが展開するためのガイドとなる。

### 6.3 実行例
```bash
# 基本実行
/prompts:upgrade-analyzer Next.js 15.4 15.5.3

# プロジェクト情報付き実行
/prompts:upgrade-analyzer Next.js 15.4 15.5.3 "Eコマースサイト、月間100万PV、決済機能とカート機能が重要、SEOとパフォーマンスが最優先"
```
