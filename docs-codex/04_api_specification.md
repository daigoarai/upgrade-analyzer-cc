# Upgrade-analyzer Codex CLI版 API仕様書

## 1. 概要

### 1.1 APIの種類
- **スラッシュコマンドAPI**: Codex CLIのスラッシュコマンド機能を使用
- **プロンプトファイルAPI**: プロンプトファイルによるAI分析実行
- **ファイル保存API**: 生成されたレポートのファイル保存

### 1.2 APIの特徴
- **RESTful API**: 非対応（プロンプトファイルベース）
- **GraphQL API**: 非対応（プロンプトファイルベース）
- **WebSocket API**: 非対応（プロンプトファイルベース）
- **プロンプトファイルAPI**: 対応（Codex CLIカスタムプロンプト機能）

## 2. スラッシュコマンドAPI

### 2.1 コマンド仕様

#### 2.1.1 コマンド名
```
/prompts:upgrade-analyzer
```

#### 2.1.2 コマンド説明
```
ソフトウェア製品のバージョンアップ影響分析レポートを生成
```

#### 2.1.3 引数ヒント
```
<製品名> <バージョンFrom> <バージョンTo> [プロジェクト情報]
```

### 2.2 引数仕様

#### 2.2.1 必須引数

| 引数名 | 型 | 必須 | 説明 | 例 |
|--------|----|----|------|-----|
| 製品名 | string | 必須 | アップグレード対象の製品名 | `Next.js` |
| バージョンFrom | string | 必須 | 現在のバージョン | `15.4` |
| バージョンTo | string | 必須 | アップグレード先のバージョン | `15.5.3` |

#### 2.2.2 オプション引数

| 引数名 | 型 | 必須 | 説明 | 例 |
|--------|----|----|------|-----|
| プロジェクト情報 | string | オプション | プロジェクトの文脈・背景・目的・特性 | `Eコマースサイト、月間100万PV` |

#### 2.2.3 引数の制約

| 引数名 | 制約 | エラーメッセージ |
|--------|------|------------------|
| 製品名 | 空文字列不可、1文字以上 | "製品名を正しく入力してください" |
| バージョンFrom | セマンティックバージョン形式推奨 | "バージョン形式が不正です。例: 15.4, 18.2.0" |
| バージョンTo | セマンティックバージョン形式推奨 | "バージョン形式が不正です。例: 15.4, 18.2.0" |
| プロジェクト情報 | 1000文字以内 | "プロジェクト情報は1000文字以内で入力してください" |

### 2.3 実行例

#### 2.3.1 基本実行
```
/prompts:upgrade-analyzer Next.js 15.4 15.5.3
```

#### 2.3.2 プロジェクト情報付き実行
```
/prompts:upgrade-analyzer Next.js 15.4 15.5.3 "Eコマースサイト、月間100万PV、決済機能とカート機能が重要、SEOとパフォーマンスが最優先"
```

#### 2.3.3 複雑なプロジェクト情報付き実行
```
/prompts:upgrade-analyzer React 18.2.0 18.3.1 "社内の勤怠管理システム、認証とアクセス制御が重要、ダウンタイム許容度低"
```

## 3. プロンプトファイルAPI

### 3.1 プロンプトファイル仕様

#### 3.1.1 ファイル形式
- **ファイル名**: `prompts/upgrade-analyzer.md`
- **形式**: JSON メタ情報 + Markdown本文
- **区切り文字**: `---`

#### 3.1.2 JSON メタ情報仕様

```json
{
  "name": "upgrade-analyzer",
  "description": "ソフトウェア製品のバージョンアップ影響分析レポートを生成",
  "argument_hint": "<製品名> <バージョンFrom> <バージョンTo> [プロジェクト情報]"
}
```

#### 3.1.3 フィールド仕様

| フィールド | 型 | 必須 | 説明 | 制約 |
|------------|----|----|------|------|
| name | string | 必須 | スラッシュコマンド名 | 英数字、ハイフン、アンダースコアのみ |
| description | string | 必須 | コマンドの説明 | 100文字以内 |
| argument_hint | string | 必須 | 引数のヒント | 200文字以内 |

### 3.2 プロンプト本文仕様

#### 3.2.1 引数プレースホルダー

Codex CLIのスラッシュコマンドは、受け取った引数を `{引数1}` から `{引数N}` までの形式でプロンプト本文に渡す。

| プレースホルダー | 対応する値 | 説明 | 例 |
|------------------|------------|------|-----|
| `{引数1}` | 製品名 | アップグレード対象の製品名 | `Next.js` |
| `{引数2}` | バージョンFrom | 現在のバージョン | `15.4` |
| `{引数3}` | バージョンTo | アップグレード先のバージョン | `15.5.3` |
| `{引数4}` | プロジェクト情報（任意） | プロジェクトの文脈・背景・目的・特性 | `Eコマースサイト、月間100万PV` |

> 備考: プロンプト本文では `{製品名}` や `{バージョンFrom}` などのガイド表記を併用しているが、実際の値は上記プレースホルダーにより代入される。

#### 3.2.2 プロンプト構造

```markdown
---
# プロンプト本文

## 1. 基本指示
- 調査対象の明確化
- 調査手順の詳細
- 出力形式の指定

## 2. 調査項目
- リリース状況確認
- 中間バージョン特定
- 段階的差分分析
- 依存関係分析
- クロスブラウザ互換性分析

## 3. レポート生成
- メタ情報生成
- 差分サマリ生成
- 主要変更点分類
- テスト戦略提案
- リスクアセスメント

## 4. ファイル保存
- 自動保存指示
- ファイル命名規則
- 保存場所指定
```

## 4. レスポンス仕様

#### 4.1.2 レスポンス内容

## 2. 差分サマリ

### 4.2 エラーレスポンス

#### 4.2.1 入力エラー

| エラーコード | エラーメッセージ | 説明 |
|--------------|------------------|------|
| E001 | "必須引数が不足しています。引数: <製品名> <バージョンFrom> <バージョンTo>" | 必須引数が不足 |
| E002 | "バージョン形式が不正です。例: 15.4, 18.2.0" | バージョン形式が不正 |
| E003 | "製品名を正しく入力してください" | 製品名が空または不正 |
| E004 | "プロジェクト情報は1000文字以内で入力してください" | プロジェクト情報が長すぎる |

#### 4.2.2 処理エラー

| エラーコード | エラーメッセージ | 説明 |
|--------------|------------------|------|
| E101 | "プロンプトファイルが見つかりません: prompts/upgrade-analyzer.md" | プロンプトファイルが見つからない |
| E102 | "JSON メタ情報の解析に失敗しました。形式を確認してください" | JSON メタ情報の解析エラー |
| E103 | "インターネット接続を確認してください" | Web検索エラー |
| E104 | "ファイル保存に失敗しました。権限を確認してください" | ファイル保存エラー |

| 警告コード | 警告メッセージ | 説明 |
|------------|----------------|------|

| W002 | "情報が不足している可能性があります。追加調査を推奨します" | 情報不足 |

## 5. ファイル保存API

### 5.1 保存仕様

#### 5.1.1 保存場所
- **ディレクトリ**: `reports/`
- **権限**: 読み書き可能
- **作成**: 存在しない場合は自動作成

#### 5.1.2 ファイル命名規則

```
{製品名}_{バージョンFrom}_to_{バージョンTo}_{YYYYMMDD}_{HHMMSS}.md
```

#### 5.1.3 命名例

```
# 基本形式
nextjs_15.4_to_15.5.3_20250128_143022.md
react_18.2.0_to_18.3.1_20250128_150315.md
postgresql_14.1_to_15.0_20250128_161045.md

# プロジェクト情報付き（オプション）
nextjs_15.4_to_15.5.3_ecommerce_20250128_143022.md
react_18.2.0_to_18.3.1_internal-tool_20250128_150315.md
```

### 5.2 保存処理

#### 5.2.1 保存手順
1. レポート内容の生成
2. ファイル名の生成
3. ディレクトリの確認・作成
4. ファイルの保存
5. 保存確認
6. ファイルパスの表示

#### 5.2.2 保存確認

| 項目 | 確認内容 |
|------|----------|
| ファイル存在 | 保存されたファイルが存在するか |
| ファイルサイズ | ファイルサイズが0より大きいか |
| ファイル内容 | レポート内容が正しく保存されているか |
| ファイル権限 | 読み取り権限があるか |

## 6. エラーハンドリング

### 6.1 エラー分類

#### 6.1.1 入力エラー（E001-E004）
- **原因**: ユーザー入力の問題
- **対応**: エラーメッセージ表示、正しい入力例の提示
- **復旧**: ユーザーによる入力修正

#### 6.1.2 処理エラー（E101-E104）
- **原因**: システム内部の問題
- **対応**: エラーメッセージ表示、問題箇所の特定
- **復旧**: システム管理者による対応

#### 6.1.3 警告（W001-W002）
- **原因**: 情報不足や不確実な状況
- **対応**: 警告メッセージ表示、追加調査の推奨
- **復旧**: ユーザーによる追加調査

### 6.2 エラーログ

#### 6.2.1 ログ形式
```
[YYYY-MM-DD HH:MM:SS] [LEVEL] [CODE] MESSAGE
```

#### 6.2.2 ログ例
```
[2025-01-28 14:30:22] [ERROR] [E001] 必須引数が不足しています。引数: <製品名> <バージョンFrom> <バージョンTo>
[2025-01-28 14:30:25] [WARN] [W001] 指定されたバージョンがリリースされていない可能性があります
[2025-01-28 14:30:30] [INFO] [I001] レポート生成完了: nextjs_15.4_to_15.5.3_20250128_143022.md
```

## 7. パフォーマンス仕様

### 7.1 処理時間

| 処理 | 目標時間 | 最大時間 |
|------|----------|----------|
| レポート生成 | 3分以内 | 5分以内 |
| ファイル保存 | 5秒以内 | 10秒以内 |
| 全体処理 | 5分以内 | 10分以内 |

### 7.2 リソース使用量

| リソース | 使用量 | 制限 |
|----------|--------|------|
| メモリ | 100MB以下 | 500MB以下 |
| ディスク | 1MB以下 | 10MB以下 |
| CPU | 50%以下 | 80%以下 |

## 8. セキュリティ仕様

### 8.1 入力検証

| 項目 | 検証内容 | 制限 |
|------|----------|------|
| 製品名 | 空文字列チェック、特殊文字チェック | 1-100文字 |
| バージョン | 形式チェック、特殊文字チェック | 1-50文字 |
| プロジェクト情報 | 長さチェック、特殊文字チェック | 0-1000文字 |

### 8.2 出力検証

| 項目 | 検証内容 | 制限 |
|------|----------|------|
| ファイル名 | 危険な文字の除去、パストラバーサル攻撃の防止 | 1-255文字 |
| ファイル内容 | 悪意のあるコンテンツの除去 | 1MB以下 |
| 保存場所 | 指定されたディレクトリ内のみ | `reports/` ディレクトリ内 |
